# Repaso de español

Free, beginner-friendly Spanish quizzes for Latin American Spanish. Everything runs in the browser: no accounts, no servers, no API keys.

**Sections:** ⭐ build-your-own quiz, question words (cuál vs qué, por qué vs porque), everyday verbs including gustar (stem changes, reflexives, worksheet-style gustar questions, filter by person), ser vs estar, nouns (cartoon face, tappable body with arm/hand, leg/foot and more, animals by group, food, clothes, house, kitchen, bedroom, bathroom, town, transport, nature, people, everyday things, with picture questions) plus a 🎲 10 random nouns pop-up and time (clock, days, months). Hobbies: hobby words (nadar, leer, bailar, tocar la guitarra…), me gusta + hobby in the style of the class gustar worksheet (gusta vs gustan, ¿Te gusta a ti…? → Sí, a mí me gusta…, ¿Les gusta a ustedes…? → a nosotros nos…, no me gusta), and tocar vs jugar. gusta or gustan?: ¿Qué le gusta más a tu hermano / mamá / tío…, X o Y? questions (always gusta), answers (A mi hermano le gustan más los mangos), ¿Cuáles te gustan…?, qué or cuáles, and switching tu → mi, a ti te → a mí me.


**Countries:** a world map where you find the country, "which country is in pink?", name the shape, flags and country names, Soy de… (I'm from…), and a timed pop quiz. The most common countries come first (Spain, Mexico, the USA, the UK, Latin America…), more join as you improve. Map data: [Natural Earth](https://www.naturalearthdata.com/) (public domain) via the world-atlas package; `tools/make-country-map.js` rebuilds `countries-map.js`.

- Each mistake is named and explained, and your weak spots come up more often.
- Difficulty goes up as you improve (tap → type → build), or pick Easy, Medium or Hard for each section. Hard time hides the digital clock and has you type the time. Time > **Clock only (hard)** shows just a clock face at any minute (like 3:47), with no hints, and you type the time (y, menos and para forms all count).
- Tap any Spanish word to see its meaning and hear it (uses your browser's own voice).
- "Who's practising?" keeps separate progress for each person on the same device.
- Progress saves in the browser. Use **Save to a file / Load from a file** to back it up or move it to another device.

## Run it
Open `index.html` in a browser, or turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
